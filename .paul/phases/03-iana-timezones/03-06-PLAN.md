<objective>
## Goal
Check placed tz values against the time information that official AIPs (GEN 2.1, or the aerodrome AD 2 entries) and the ERSA publish. Count matches and list mismatches by airport_id. Resolve each mismatch from a cited non-AIP source, or set it NULL.

## Purpose
This is an independent check on 03-03 and 03-04 placements, which rest on tzdata and statute citations. It does not gate the release. Operator, verbatim 2026-11-20 (relayed by sqwkd): "Official source checks do not hold up release."
</objective>

- **Comparison dates, fixed before AC-1:** northern hemisphere winter **2026-01-15** and summer **2026-07-15**. Southern hemisphere: the same two dates, with the seasons reversed (2026-07-15 is the southern winter). An airport's hemisphere is the sign of its latitude in the build.
- **Scope rule (sqwkd condition 2):** for each source, record whether it is a country-level statement (GEN 2.1) or per-aerodrome entries (AD 2). For multi-zone countries (AU, BR, RU, ID and the 03-04 set), a GEN 2.1 statement checks only the zones it names; it never checks a specific airport's zone. "Count checked" is reconciled against the build's present, placed airports in that country, and the gap is stated.
- **Predictions (condition 3):** after AC-1 and before AC-2, write each available source's expected match count or rate, and any expected mismatch ids, into this PLAN.
- **Stops (condition 4):** AC-1 judgement calls go to sqwkd before any comparison. So does any source whose edition is older than the tzdata 2026f change it would be compared against.

## AC-1: Source availability survey (first, before any comparison)
For AU (ERSA, Airservices), BR (DECEA AIP), RU, ID and each 03-04 country, record whether a free, no-login, official edition is reachable with the default client: URL, edition/effective date, and the GEN 2.1 or AD section that states local time. If a source is blocked, behind a login, or needs a workaround, record it as "not checked" with the reason. Nothing is fetched twice to get around a refusal.

## AC-2: Comparison, nothing stored
For each available source, compare the stated standard offset and DST rule (on a winter and a summer date) with the airport's tz on the post-01-04 build, for the airports the source covers. Keep only these in the repo and SUMMARY: edition, count checked, count matched, and the airport_ids of mismatches. No offsets and no copied text. Working files stay in the scratchpad and are deleted after APPLY.

## AC-3: Mismatch resolution
For each mismatch, either find a cited non-AIP source (statute, tzdata, a government gazette) that confirms the current placement or a different one, and update rules or overrides with that citation, or force the airport NULL. **The NULL mechanism is a blank-tz row in overrides.csv** (tz_unplaced = source_conflict), with the reason and the non-AIP citation in its note. unplaced_by_design does not force NULL (measured in 01-04). A forced-NULL airport may also get an unplaced_by_design row, provided the 01-04 verify check ("no unplaced_by_design id is placed") stays consistent. The AIP is never cited as the placement source.

## AC-4: Checks
On the post-01-04 build, `verify --previous` exits 0 and `tz gate` exits 0. The SUMMARY records the gate counts before and after.
</acceptance_criteria>
