<objective>
## Goal
Identity `iso_country` for TNCE (AP0019780) and TNCM (AP0019781) is NASR's retired "AN" (Netherlands Antilles, dissolved 2010). It should hold the current ISO 3166-1 code, BQ and SX, the codes that OurAirports and the tz layer already use. A NASR legacy code never reaches the identity table: it becomes the ISO successor that the attached OurAirports row states, or NULL when no source states one.

## Purpose
This is the Phase 1 release blocker (sqwkd 2026-11-19: "Phase 1 handles it before release, with its own review and verify --previous"). cv-aviation reads `airport_identity.iso_country` as an ISO 3166-1 code.

## Output
A small identity.py change, a verify check, tests, a README line, and a fresh 2026-10-29 build whose only difference from tz8 is these two values. No DDL change.
</objective>

<acceptance_criteria>
## AC-1: Identity country rule
For an entity with a NASR observation whose country is a key of `NASR_LEGACY_COUNTRIES`:
- **(a)** if an attached OurAirports row states a country in that key's successor set, identity `iso_country` is that country;
- **(b)** otherwise, if the previous identity already holds a successor-set country, it is kept (last-seen, source-stated earlier);
- **(c)** otherwise it is NULL. A legacy code is never written and a successor is never guessed. AN has three successors, so position or ICAO prefix would be a guess.
Every other entity keeps `primary.iso_country` exactly as today. The pairing gate and `placement_inputs` are unchanged.

## AC-2: verify refuses a retired code
`check_identity` reports a problem for any `airport_identity.iso_country` that is a key of `NASR_LEGACY_COUNTRIES`. The constant is imported, not copied. Test: a fixture row with "AN" fails, and BQ/SX/NULL pass.

## AC-3: Tests
In `tests/test_identity.py`:
- the existing TNCM pairing test also asserts identity `iso_country == "SX"`;
- new cases: (b) NASR-only AN carrying a previous SX keeps SX; (c) NASR-only AN with no previous gives NULL; an OurAirports row whose country is not a successor (e.g. "US") does not supply the country; a non-legacy NASR country (CA) is unchanged.
ruff is clean and the full pytest suite passes.
